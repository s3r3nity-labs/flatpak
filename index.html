Installing

Click an app's Install button and open the downloaded file. Your app store (Discover, GNOME Software, …) installs it and adds this repository, so updates arrive with your other apps. Or in a terminal:

flatpak install --user https://s3r3nity-labs.github.io/flatpak/org.s3r3nity.HomeSync.flatpakref
flatpak install --user https://s3r3nity-labs.github.io/flatpak/org.s3r3nity.MangoHudFPSSwitch.flatpakref

Adding the repository only

flatpak remote-add --user --if-not-exists s3r3nity-labs https://s3r3nity-labs.github.io/flatpak/s3r3nity-labs.flatpakrepo

Removing

flatpak uninstall --user org.s3r3nity.HomeSync org.s3r3nity.MangoHudFPSSwitch
flatpak remote-delete --user s3r3nity-labs
